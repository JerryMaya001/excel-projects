# HR Dashboard

## Project Overview

This project demonstrates the creation of an interactive HR dashboard in Microsoft Excel to summarize workforce metrics and support decision-making.

---

## Objective

To design a dashboard that presents key HR metrics in a clear and interactive format.

The dashboard includes:

- Employee Count
- Average KPI
- Average Salary
- PivotTables
- PivotCharts
- Slicers
- Conditional Formatting
